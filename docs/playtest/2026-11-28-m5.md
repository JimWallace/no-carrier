The bots on the test objective:

```bash
swift build -c release
```

```bash
.build/release/carrier sim --runs 500 --objective infiltrate --bot ghost
```

On the map: `SCAN N` spends the tick to reveal a `[N?]` node; `INFO N`
shows what you know; `JACK OUT` ends the contract. In a fight, when AUTH
falls, press 1 to CLAIM or 2 to GHOST.
