## What to run

```bash
swift run carrier play --objective exfiltration
```

The TARGET shows as `$` on the map, with its file size above the map.
Breach its FIREWALL and AUTH and the TRANSFER starts. Stay until it is
complete, LOGOUT with the file, then type `JACK OUT`. The payout depends
on the Alert state when you jack out.
