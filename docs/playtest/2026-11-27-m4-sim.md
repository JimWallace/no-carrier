# Simulation: M4, first tuning check

Not a human playtest. A first read of the tuning with the greedy bot, to
set beside the M3 playtest.

## Build

Branch `claude/beautiful-meitner-rkulti`, after the M4 commit, release
build.

```bash
swift build -c release
```

```bash
.build/release/carrier sim --runs 500 --seed 1994
```

## As tuned

Over 500 contracts, the greedy bot:

- wins 0%, flatlines 71%, is traced 29%;
- reaches ROOT in 276 contracts and loses all 276;
- ends with Trace 74.7 on average, after 9.7 ticks and 6.3 fights.

The random bot (`--bot random`) is traced in 98% and wins none.

## Variants

Each variant is a copy of `Sources/CarrierContent/Content/` passed with
`--content`. Nothing in the repository was changed.

| Variant | Won | Flatlined | Traced |
|---|---|---|---|
| As tuned | 0% | 71% | 29% |
| OMEGA 21064 at tier 2 (`hardware.json`) | 1% | 73% | 26% |
| ROOT at 16 MB, so THE OPERATOR alone (`tuning.json`; layers 29/29/23 to keep 30/30/24) | 9% | 38% | 53% |
| Both | 33% | 35% | 32% |

The ICE count at ROOT matters more than the CPU tier. With both changes,
the bot still loses two contracts in three, most of them to Integrity and
Trace before or at ROOT.
