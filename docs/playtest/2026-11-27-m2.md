## What to run

The procgen readout (M1):

```bash
swift run carrier gen --count 8
```

A neutral fight, then one against a sysop machine with a KERNEL (M2):

```bash
swift run carrier fight
```

```bash
swift run carrier fight --role sysop
```

Record a session that shows a bug, and play it back:

```bash
swift run carrier fight --seed 1994 --record bug.replay.json
```

```bash
swift run carrier replay bug.replay.json
```
