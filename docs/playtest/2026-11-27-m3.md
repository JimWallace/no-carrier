they were answered.

## What to run

```bash
swift run carrier play
```

To record a session that shows a bug, and play it back:

```bash
swift run carrier play --seed 1994 --record bug.replay.json
```

```bash
swift run carrier replay bug.replay.json
```

On the map, press a node number to attack it. Type `REINFORCE N`, `WAIT`,
`SCAN N`, `DECK` or `HELP`.

## Questions

1. **Is the map interesting at this size?** Do the routes to ROOT feel
   different?
2. **Does Payload carrying create real decisions?** Did you go for a VIRUS
   node early, and did PAYLOAD clog your neutral fights?
3. **Is Trace pressure about right?** Where did Trace come from: drift,
   SWEEP, ICE, LOGOUT?
4. Did CONTEST and REINFORCE matter, or were they noise?
5. Was a DATA upgrade worth a fight? Which one did you take?
6. THE OPERATOR: did the second phase feel like a boss?
